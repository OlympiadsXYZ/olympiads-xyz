## What works: the subscription agent route (no API money)

Each paper gets one Opus 5.5 agent. It reads the page images, reviews its own
figure crops, then runs `run.mjs` through upload, free mechanical checks (text
layer and printed regions), repair, receipt and promotion. If a paper is parked,
the agent fixes it from the page, at most twice.

Results so far:

- 20-paper pilot: 20 promoted.
- Tranche 1: 14 of 20 promoted.
- Tranche 2: 23 of 23 finished papers promoted. The other 17 were killed by a
  DNS outage.

Cost is about 2 weekly-meter points per 20 papers on Pro. The meter was at 92%
before tranche 2 and is at **96% weekly now (02:15Z Sep 23; resets 2026-09-26
02:00Z)**, with 5-hour at 54%. The 17-paper retry alone costs about 3–4 points,
so going on this week needs the banked reset.

- Workflow script:
  [handoff-2026-09-22/agent-route.workflow.js](handoff-2026-09-22/agent-route.workflow.js).
  Run it with the Workflow tool:
  `args = {repo: "<absolute repo path>", queue: "docs/handoff-2026-09-22/queue-retry.json", papers: [{id: "nao-2014-iv-st"}, ...]}`
- Agents start papers with `node scripts/tx/queue-start.mjs <queue> <id>`, which
  takes the archive keys from the queue file. **Never type archive keys by
  hand.** Hand-typed keys went wrong twice this session (once a wrong file was
  read, once caught before it ran). Args carry ids only.
- One paper by hand: `node scripts/tx/queue-start.mjs <queue> <id>`. Exit 2
  means it prints the reader task. Write the candidate, run
  `figures.mjs <id> <candidate> --dry-run`, review the crops, then
  `run.mjs <id> --continue`. On exit 3, fix from the page and run
  `--continue --retry --repaired <file>`. After promotion, run
  `prepare.mjs <id> --gc`.
- Ship with `node scripts/ship.mjs`, which runs the gates, commits and pushes.
  GitHub Actions builds the `deploy` branch and Vercel serves it. Then check the
  live index at olympiads.xyz.

### How a tranche runs (desktop, 2026-09-23)

1. Build the args from the keep list: drop papers already in content/problems
   and papers whose job already has an agent reader. Then pre-check:
   `node scripts/tx/tranche-dupes.mjs <queue> <args.json> --no-prepare`. Twins
   of held papers are expected; anything else at ≥ 90% overlap gets held.
2. Run the Workflow tool with `scriptPath` set to
   `handoff-2026-09-22/agent-route.workflow.js`. Arm a Monitor that fires when
   any agent-\*.jsonl in the run folder passes 60 MB (a runaway loop).
3. Tally the journal. Read the notes for gaming: invisible characters, rewritten
   LaTeX, tables turned into images.
4. For papers parked only on agreement edits, run
   `node scripts/tx/dp28-restore.mjs <ids>`, then
   `run.mjs <id> --continue --retry --repaired <tmp/tx/<id>/candidates/agent__opus-5-5.dp28.json>`.
5. Ship with `node scripts/ship.mjs` only when no deploy is in flight: a push
   cancels the running build. Then check a new page on the live site.
6. Old API jobs that are `done`, have `promote:false` and no content file:
   `node scripts/tx/fresh-reset.mjs <ids>`, then read them again.

  `~/.config/olympiads-xyz/providers.env`.
- With several Chromes connected, pick the one matching the host OS. Never ask
  which.

  spent. Only the subscriptions are left. **Stop at 50% of the weekly meter**
  (Margulan, 2026-09-26; the old rule was 96–97%).

  _identical_ args, so the finished agents return cached results.
