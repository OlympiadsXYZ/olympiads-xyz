## Условие

*Plotting a semi-log graph*

On semi-log graph paper, one axis has a log scale and the other axis has a linear scale. The idea here is we use semi-log paper so that we can more easily see details for small values as well as large values.

Plot the data points on the semi-log graph paper below with

x-axis = Recurrence interval (T) (year), and y-axis = discharge (cfs x 1000).

Then, draw a best-fit (not point-to-point) smooth curve to fit the data points. This is the flood-frequency curve for the given river at the specified location.
