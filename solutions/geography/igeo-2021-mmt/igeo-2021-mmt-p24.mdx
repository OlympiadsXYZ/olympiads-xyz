## Условие

The figure shows simplified maps for transport geography of three regions.

Which region is represented by which simplified map?

A. region A = Sub-Sahara Africa | region B = Western Europe | region C = Oceania

B. region A = Central America | region B = South America | region C = Middle East

C. region A = Middle East | region B = Oceania | region C = Mediterranean

D. region A = North America | region B = Western Europe | region C = East and Southeast Asia
