## Условие

This map depicts ships around Istanbul on May 24, 2021 at 21.00 PM local time. Each color represents a certain kind of ship.

Which photo corresponds to which numbered ships on the map?

A. photo A = ship 1, photo B = ship 2, photo C = ship 3

B. photo A = ship 1, photo B = ship 3, photo C = ship 2

C. photo A = ship 2, photo B = ship 1, photo C = ship 3

D. photo A = ship 2, photo B = ship 3, photo C = ship 1
