*Московская астрономическая олимпиада. Наблюдательный тур. Московский планетарий. 7 марта 2017 года · 7 март 2017 г.*

## Условие

Вам демонстрируйте вид звёздного неба, видимого предстоящей ночью из одного из городов Российской Федерации. Показан небесный меридиан и небесный вертикал, пересекающий горизонт в точках востока и запада.

Запишите в таблицу в бланке ответов, в какой части неба находятся перечисленные объекты из каталога Мессье:

8-9 классы: М13, М16, М29, М42, М81, М87.

10-11 классы: M8, М13, М16, М29, М42, M45, М81, М87, М101, M104

## Отговори

<Spoiler title="Покажи отговорите">

- 60°–90°: М 13 (Юго-Восток), М 101 (Северо-Запад); 30°–60°: М 29 (Северо-Восток), М 87 (Юго-Запад), M 81 (Северо-Запад); 0°–30°: М 8, М 16 (Юго-Восток), М 104 (Юго-Запад); < 0°: М 42, М 45.

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

В заданиях 2-3 демонстрировалось звёздное небо в Кисловодске в 4:30 (UT+3) 8 марта 2017 года.

| | Северо-Восток | Юго-Восток | Юго-Запад | Северо-Запад |
|---|---|---|---|---|
| Высота | 180° – 270° | 270° – 0° | 0° – 90° | 90° – 180° |
| 60° – 90° | | М 13 | | М 101 |
| 30° – 60° | М 29 | | М 87 | M 81 |
| 0° – 30° | | М 8, М 16 | М 104 | |
| < 0° | М 42, М 45 | | | |

Каждый объект оценивался в 1 балл.


</Spoiler>
