*Московская астрономическая олимпиада. Наблюдательный тур. Московский планетарий. 7 марта 2017 года · 7 март 2017 г. · 4 т.*

## Условие

Вам демонстрируется ускоренное суточное движение небесной сферы, вызванное вращением планеты вокруг своей оси. Проецируется небесный вертикал со шкалой высоты, показ Солнца, Луны и планет отключён. Определите широту места наблюдения. Погрешность указывать не требуется.

## Отговори

<Spoiler title="Покажи отговорите">

- 32 ° с.ш.

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

| | |
|---|---|
| Широта | φ = 32° с.ш., критерии: 31 ≤ φ ≤ 33° - 4 балла, 30 ≤ φ < 31°, 33° < φ ≤ 34° - 3 балла, 29 ≤ φ < 30°, 34° < φ ≤ 35° - 2 балла, 28 ≤ φ < 29°, 35° φ ≤ 36° - 1 балл |
| | При неуказании с. ш. оценка снижалась на 1 балл, при указании ю.ш. на 2 балла. |


</Spoiler>
