*2 Дистанционный этап 72й Московской Астрономической Олимпиады 5-11 класс*

## Условие

**К каким созвездиям относятся эти звёзды?**

| Звёзды | Созвездия |
|---|---|
| А. Ригель | 1. Киль |
| Б. Альдебаран | 2. Лебедь |
| В. Канопус | 3. Лев |
| Г. Вега | 4. Лира |
|  | 5. Орион |
|  | 6. Пегас |
|  | 7. Персей |
|  | 8. Телец |
|  | 9. Центавр |

Запишите ответ в виде четырёх пар (буква звезды и номер созвездия), разделённых пробелами.

(Например, А1 Б2 В3 Г4)

## Отговори

<Spoiler title="Покажи отговорите">

- А5 Б8 В1 Г4

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

*Ответ:* ***А5 Б8 В1 Г4***

*Ригель – Орион*

*Альдебаран – Телец*

*Канопус – Киль*

*Вега – Лира*


</Spoiler>
