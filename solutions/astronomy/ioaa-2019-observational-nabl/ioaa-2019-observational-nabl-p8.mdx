<details>
<summary>Бележка</summary>

Telescope: 150/750 Newton

Eyepieces: 25 mm, 10 mm, Barlow lens: 2x

**Note:**

- Telescope is already polar aligned.
- In case of bad sky conditions at low altitudes, task 1 and 2 will be replaced by alternative tasks 1 and 2 (see page 3). In this situation, the telescope assistant will cross out Tasks 1 and 2.
- You have to use 25 mm eyepiece for tasks 1, 3 and 4.
- For these tasks, if you finish before the allotted time, you must keep tracking the object with the telescope till the end of allotted time. The telescope assistant will check the object only at the end of the allotted time.
- For task 2, we recommend using 10 mm eyepiece and Barlow 2x.
- For task 5, you are not allowed to use the telescope.

**QUESTIONS / TASKS:**

**1.1.** There are 3 novae on the projected sky at 2nd magnitude. Mark their positions by circles on the star chart. (Please circle only 3 stars. If there are more than 3 circles, then each one in a wrong location will result in 1 point deduction.)

**1.2.** The Messier objects have been removed from the star chart given you. Mark all the Messier list globular clusters present in the projected sky on the star chart using crosses (X) and write the Messier number of each object near the cross marks.

**1.3.** The projected sky corresponds to the second half of which month (at midnight CEST) in Keszthely? Circle the correct month.

JAN / FEB / MAR / APR / MAY / JUN / JUL / AUG / SEP / OCT / NOV / DEC

**1.4.** What is the local sidereal time? (To an accuracy of 15 minutes.)

**1.5.** List six zodiacal constellations, which are partly or entirely visible. (Use the official IAU abbreviations or IAU designation. Every constellation named which is not visible in the projected sky will result in 1 point deduction.)

## Решение

Planetarium round — problems, solutions, marking

<ProblemSection id="solution-answer-1-1">

### 1.1.

See the stellar map below. **Marking:** 3 points per nova; any wrong position: minus 1 point. **Maximum: 9 points.**

</ProblemSection>

<ProblemSection id="solution-answer-1-2">

### 1.2.

M2, M13, M15, M30, M56, M71, M72, M92 are visible.

**Marking:** good position (signed by X): max. 3 points/each. See map below with 5° and 10° diameter circles. If X is inside the inner circle: 2 points; inside the outer circle: 1 point. Good Messier number: 1 point each. **Maximum: 24 points.** The printed marking map also labels M79 near the horizon; that label is absent from the printed answer list above.

</ProblemSection>

<ProblemSection id="solution-answer-1-3">

### 1.3.

October (19th October, 2019). **Marking:** October: 2 points; September or November: 1 point. **Maximum: 2 points.**

</ProblemSection>

<ProblemSection id="solution-answer-1-4">

### 1.4.

1h 00m. Gamma Cassiopeiae is at upper culmination; its right ascension is 00h 57m. **Marking:** 1h 00m: 3 points; 1h 15m or 0h 45m: 2 points; 1h 30m or 0h 30m: 1 point. **Maximum: 3 points.**

</ProblemSection>

<ProblemSection id="solution-answer-1-5">

### 1.5.

Sgr, Cap, Aqr, Psc, Ari, Tau, Gem, Cnc. **Marking:** 1 point each. **Maximum: 6 points.**

</ProblemSection>
