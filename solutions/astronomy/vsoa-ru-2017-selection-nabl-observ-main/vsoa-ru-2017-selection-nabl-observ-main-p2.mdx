## Условие

Приложение № 2: Негатив фотографии звёздного неба.

**▹** Проведите линии астеризмов 10 созвездий и подпишите их, используя трёхбуквенные обозначения IAU (например, UMi). Вы можете также использовать в качестве подписей названия созвездий на русском языке, однако такие отметки будут засчитываться «с уценкой».

**▹** Обведите следующие звёзды «в кружок» ○ и около каждого напишите соответствующий номер:

| Обозначение | Значение |
| :-- | :-- |
| 0 | $\lambda$ Sco |
| 1 | Вега |
| 2 | Альбирео |
| 3 | Альтаир |
| 4 | $\alpha$ CrB |
| 5 | Садр |
| 6 | Шелиак |
| 7 | $\gamma$ Sge |

**▹** Отметьте объекты далёкого космоса символом △ и около каждого △ подпишите его номер объекта по каталогу Мессье: тум. Лагуна, тум. Кольцо, М7, М13, М30.

**▹** Обозначьте указанные точки крестом × и укажите рядом соответствующие буквы-обозначения:

| Обозначение | Значение |
| :-- | :-- |
| A | Северный полюс эклиптики |
| B | Апекс Солнца |
| C | Зимнее солнцестояние |
| D | Пересечение галактического и небесного экваторов |

## Решение

<Warning title="Непълно решение">
Разметка оригинального ответа использует номера 1–8 для звёзд вместо 0–7; номера 1–4 для особых точек вместо A–D и номера 1–5 у треугольников вместо обозначений каталога Мессье. Эта отличающаяся система подписей сохранена; соответствующая легенда в файле не приведена.
</Warning>
