Восстановлены все21 архивное приложение: исходные изображения и карты, а также имеющиеся размеченные ответы. Ключи к заданиям1–4 и6 частичные; ключи к заданиям5 и7 в предоставленной папке отсутствуют. Повторяющиеся номера приложений и пример «M41 — Ori» воспроизведены как в оригинале. ## Условие

Приложение № 1: Карта звёздного неба в цилиндрической проекции на 12 апреля 2017 года в Москве в 9:20 утра по местному времени.

**▹** Проведите линии следующих больших кругов небесной сферы на эпоху составления карты и подпишите их, используя следующие обозначения:

| Обозначение | Значение |
| :-- | :-- |
| Q | Небесный экватор |
| G | Галактический экватор |
| E | Эклиптика |
| H | Горизонт |
| M | Небесный меридиан |
| J | Эклиптика на эпоху 11000 г. до н. э. |

**▹** Обозначьте указанные точки крестом × и укажите рядом соответствующие им номера:

| Обозначение | Значение |
| :-- | :-- |
| 1 | Весеннее равноденствие |
| 2 | Осеннее равноденствие |
| 3 | Зимнее солнцестояние |
| 4 | Летнее солнцестояние |
| 5 | Северный полюс галактики |
| 6 | Южный полюс галактики |

**▹** Обведите следующие звёзды «в кружок» ○ и около каждого напишите соответствующий номер:

| Обозначение | Значение |
| :-- | :-- |
| 7 | Альфард |
| 8 | Альнитак |
| 9 | Альбирео |
| 10 | Капелла |
| 11 | Растабан |
| 12 | Маркаб |
| 13 | Таразед |
| 14 | Мирзам |
| 15 | Саргас |
| 16 | $\alpha$ UMi |

**▹** Отметьте объекты Мессье символом △ и укажите соответствующие буквы-обозначения:

| Обозначение | Значение |
| :-- | :-- |
| a | M13 |
| b | M67 |
| c | M27 |
| d | M71 |
| e | M8 |
| f | M30 |
| g | M51 |
| h | M44 |
| i | M77 |
| j | M1 |

## Решение

<Warning title="Непълно решение">
На карте ответа не обозначены эклиптика эпохи 11000 г. до н. э. (J), звезда16 и буквенные обозначения объектов Мессье. Линии экватора и эклиптики подписаны EQ и EC, тогда как в условии — Q и E.
</Warning>
