## Условие

Перед Вами фото пяти тел Солнечной системы (фотобумага). Расположите их по размерам – от самого маленького до самого большого.

## Решение

<Spoiler title="Покажи официалното решение">

Чем крупнее объект, тем легче ему сохранять сферически-симметричную форму. Самый крупный здесь C — Меркурий, диаметр 4880 км. Следующая по размеру A — Церера (900 км), затем B — Веста (550 км).

На фото E рядом с крупным телом видно маленькое. Это Ида со спутником Дактилем, размер Иды 60 км. Оставшийся астероид D — Эрос, наиболее неправильной формы и самый маленький среди представленных тел (30 км).

**Ответ:** D, E, B, A, C

**Критерии оценивания**

Оценка определяется числом правильных пар в ответе участника аналогично заданию 1.

Из пяти объектов получается 10 пар. Для каждой пары проверяется взаимный порядок двух букв в ответе, даже если они не соседние. Если в ответе встречаются противоположные порядки одной пары (например, AB и BA в ABAB или ABAC), все вхождения этой пары исключаются. Если пара повторена без противоположного порядка (например, в AABB), она учитывается один раз. При 0 правильных пар 1 компенсационный балл ставится только за полный строго обратный порядок без пропусков и повторов. В остальных случаях при 0 правильных пар ставится 0 баллов.

| N | Баллы |
| --- | --- |
| 0 | 0 |
| 1 | 0 |
| 2 | 0 |
| 3 | 1 |
| 4 | 1 |
| 5 | 2 |
| 6 | 2 |
| 7 | 3 |
| 8 | 3 |
| 9 | 4 |
| 10 | 5 |


</Spoiler>
