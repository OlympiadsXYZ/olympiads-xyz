*Летние учебно-тренировочные сборы по астрономии. 6 июля 2017 г. Теоретический тур · 6 юли 2017 г. · 25 т.*

## Условие

При фотографических наблюдениях рассеянного скопления М44 с помощью телескопа ТАЛ-1 (рефлектор Ньютона) и соосно закреплённого фотоаппарата (диаметр объектива $\Delta = 100$ мм), бедному астроному пришлось его гидировать вручную. К сожалению, в созвездии Рака неподалеку от скопления не нашлось ярких звёзд, кроме звезды $\varepsilon$ Cnc ($m = 6.29^m$).

Вспомнив наставления своего преподавателя, астроном расфокусировал звезду насколько это было возможно и начал наблюдения, в ходе которых получил $N = 10$ фотографий с выдержкой каждой по $T = 2$ мин. Квантовая эффективность используемой камеры $\eta = 42\%$.

Зависимость количества отсчётов в каждом пикселе конечного изображения после компьютерной обработки прямо пропорциональна квадратному корню количества фотографий: $E_f = E_0\sqrt{N}$; ошибка гидирования обратно пропорциональна размеру изображения звезды и для сфокусированной звезды составляет $1'$.

Определите предельную звёздную величину изображения, полученного после компьютерной обработки, используя сведения о телескопе ТАЛ-1, приведённые в таблице:

| | |
|---|---|
| Диаметр главного зеркала | $D = 110$ мм |
| Фокусное расстояние | $F = 806$ мм |
| Малая ось вторичного зеркала | $d = 20$ мм |

## Отговори

<Spoiler title="Покажи отговорите">

- 19.6 m

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

(А. Шепелев)

**Решение:** Определим эффективную площадь входного отверстия телескопа. Для этого вычтем из площади главного зеркала площадь, затеняемую вторичным зеркалом:

$$S = \frac{\pi}{4}\left(D^2 - d^2\right) = 9.2\cdot 10^3\ \text{мм}^2, \qquad (25)$$

где $d$ — малая ось вторичного зеркала — диаметр его проекции на главное зеркало.

Телескоп собирает в $\xi$ раз больше света, чем невооруженный глаз; $\xi$ есть отношение площадей входного отверстия и зрачка невооруженного глаза (диаметр $D_{\text{г}} = 6$ мм):

$$\xi = \frac{S}{\pi D_{\text{г}}^2/4} = 325. \qquad (26)$$

Оценим максимальный радиус изображения «в расфокусе», при котором его ещё видно ($m_{\text{г}} = 6^m$), используя формулу Погсона и значение $\xi$:

$$\frac{R}{R_0} = \sqrt{\xi}\cdot 10^{0.2(m_{\text{г}} - m)} = 15.8, \qquad (27)$$

где $R_0$ — радиус изображения сфокусированной звезды. Согласно утверждению из условия задачи, ошибка гидирования составляет

$$\sigma = 60'' \cdot \frac{R_0}{R} = 3.8''. \qquad (28)$$

Найдём дифракционное разрешение объектива фотоаппарата для видимого света (длина волны $\lambda \sim 0.5$ мкм):

$$\beta = \frac{1.22\lambda}{\Delta} \simeq 1.3''. \qquad (29)$$

Принимая квантовую эффективность глаза равной $\eta_{\text{г}} = 4\%$, его временное разрешение — $T_{\text{г}} = 0.3$ с, получим с использованием формулы Погсона искомую предельную звёздную величину:

$$m_{\mathrm{lim}} = m_{\text{г}} + 2.5\lg\xi - 5\lg\frac{\beta + \sigma}{\beta} + 2.5\lg\frac{\eta}{\eta_{\text{г}}} + 2.5\lg\frac{T}{T_{\text{г}}} + 1.25\lg N = 19.6^m. \qquad (30)$$


</Spoiler>
