*Задачи наблюдательного тура · 22 октомври 2002 г.*

## Условие

Сейчас Вы посетите 3 наблюдательных пункта.

С каждого пункта Вам будет видна небольшая область неба.

В каждом пункте впишите в таблицу:

- Не более двух видимых Вами созвездий (можно также назвать 1–2 звезды);
- Направление, в котором Вы смотрите, относительно плоскости нашей Галактики.

(например, на ее центр, к северу от её плоскости и т. п.).

Время работы на каждом пункте не более трех минут.

| Пункт | Созвездие (звезда) | Направление в Галактике |
| --- | --- | --- |
| 1 | | |
| 2 | | |
| 3 | | |
