## Условие

***Условие.*** Для феномена, описанного в задаче № 15, c использованием лишь 1) фотографий рис. 4 и представленной на них информации, 2) значения экваториального радиуса Юпитера $\mathfrak{R}^{(e)}_J = 71492$ км, 3) предположения о круговых орбитах наблюдаемых спутников и 4) точных значений орбитальных скоростей спутников, представленных в таблице 1, оцените радиусы их орбит, сидерические периоды обращения. Определите абсолютную и относительную ошибку определения искомых величин с использованием точных значений, представленных в таблице 1. (14 баллов).

## Решение

<Spoiler title="Покажи официалното решение">

Рассмотрим положение спутника $S_1$ на орбите (см. рис. 10.б). В данном положении он порождает тень на поверхности планеты $T_1$. Земному наблюдателю, лишенному восприятия глубины изображения (в силу большой удаленности объектов), видится положение центра тени в точке P (все объекты как бы находятся в одной картинной плоскости). Треугольник $\triangle S_1T_1P$ является прямоугольным, следовательно для него можно записать соотношение вида:

$$
\sin\alpha = \frac{S_1P}{S_1T_1} = \frac{d_1 - h_1}{r - \mathfrak{R}^{(e)}_J}.
$$

здесь $d_1, h_1$ –видимые расстояния спутника и его тени соответственно от оси вращения планеты (геометрического центра планеты); $r$ – радиус орбиты спутника; $\alpha$ – угол (фазовый угол) между направлением на наблюдателя и на Солнце, если смотреть из центра Юпитера. Очевидно, что данный угол является малым, на это указывает также близость даты получения фотографии к дате противостояния (7.02.2015 г). Поскольку промежуток времени между моментами получения данных фотографий $\Delta t = 42$ мин является относительно малым, то можно полагать, что данный угол один и тот же на обеих фотографиях.

Запишем выражения для $\sin\alpha$ (согласно, рис. 9) и приравняем правые части в случае 1) Каллисто и Ио по первой фотографии и 2) Евпропы и Каллисто по второй фотографии:

$$
\frac{d^{(1)}_C + h^{(1)}_C}{r_C - \bar{\mathfrak{R}}^{(e)}_J} = \frac{h^{(1)}_I - d^{(1)}_I}{r_I - \bar{\mathfrak{R}}^{(e)}_J}, \qquad (20)
$$

$$
\frac{d^{(2)}_C + h^{(2)}_C}{r_C - \bar{\mathfrak{R}}^{(e)}_J} = \frac{d^{(2)}_E - h^{(2)}_E}{r_E - \bar{\mathfrak{R}}^{(e)}_J}, \qquad (21)
$$

С другой стороны, орбитальные скорости спутников связаны с радиусами их орбит соотношениями вида (выражения следуют из второго закона, записанного для спутника, движущегося по круговой орбите):

$$
r_C = \frac{G\,\mathfrak{M}_J}{V^2_C}, \ r_I = \frac{G\,\mathfrak{M}_J}{V^2_I}, \ r_E = \frac{G\,\mathfrak{M}_E}{V^2_C}, \ \Rightarrow \qquad (22)
$$

$$
\frac{r_C}{r_I} = \left(\frac{V_I}{V_C}\right)^2, \ \ \frac{r_C}{r_E} = \left(\frac{V_E}{V_C}\right)^2. \qquad (23)
$$

Из систем уравнений (20),(21), (23) составим две замкнутые системы уравнений относительно радиусов орбит спутников.

$$
\left.\begin{cases} r_I - \bar{\mathfrak{R}}^{(e)}_J = A_1(r_C - \bar{\mathfrak{R}}^{(e)}_J), \\ \frac{r_C}{r_I} = \left(\frac{V_I}{V_C}\right)^2 \end{cases}\right\}, \ \text{ где } \ A_1 = \frac{h^{(1)}_I - d^{(1)}_I}{d^{(1)}_C + h^{(1)}_C}. \qquad (24)
$$

$$
\left.\begin{cases} r_E - \bar{\mathfrak{R}}^{(e)}_J = A_2(r_C - \bar{\mathfrak{R}}^{(e)}_J), \\ \frac{r_C}{r_E} = \left(\frac{V_E}{V_C}\right)^2 \end{cases}\right\}, \ \text{ где } \ A_2 = \frac{d^{(2)}_E - h^{(2)}_E}{d^{(2)}_C + h^{(2)}_C}. \qquad (25)
$$

Разрешая полученные системы уравнений относительно искомых величин, в результате получаем

$$
r_I = \mathfrak{R}^{(e)}_J\left(\frac{1 - A_1}{1 - A_1(V_I/V_C)^2}\right), \ \ r_C = r_I\left(\frac{V_I}{V_C}\right)^2, \qquad (26)
$$

$$
r_E = \mathfrak{R}^{(e)}_J\left(\frac{1 - A_2}{1 - A_2(V_E/V_C)^2}\right), \ \ r_C = r_E\left(\frac{V_E}{V_C}\right)^2. \qquad (27)
$$

Очевидно, что полученные результаты наиболее чувствительны к значениям орбитальных скоростей спутников, которые в прошлой задаче определены со значительной ошибкой (из-за одного измерения). Поэтому в решении данной задачи рекомендуется использовать их табличные значения (см. таблицу 6).

Далее, измеряя по фотографии геометрические параметры, в итоге получаем $h^{(1)}_I = 30.5$ мм, $d^{(1)}_I = 19$ мм, $h^{(1)}_C = 16.5$ мм, $d^{(1)}_C = 42.5$ мм, $h^{(2)}_C = 29$ мм, $d^{(2)}_C = 30$ мм, $h^{(2)}_E = 27$ мм, $d^{(2)}_E = 46.5$ мм. Затем вычисляем $A_1 = 0.1949$, $A_2 = 0.3305$. Используя значения орбитальных скоростей спутников, представленные в таблице 6, получаем $(\frac{V_I}{V_C})^2 = 4.4642$, $(\frac{V_E}{V_C})^2 = 2.8049$. В итоге, вычисленные радиусы орбит есть

$$
r_I = 443002\ \text{км}, \ \ r_C = 1977650\ \text{км}, \ \ r_E = 655844\ \text{км}, \ \ r_C = 1839578\ \text{км}.
$$

ошибки определения данных величин есть:

$$
\Delta r_I = |r_I - r^{(0)}_I| = 21302\ \text{км}, \ \ \varepsilon_{r_I} = \frac{\Delta r_I}{r_I} \times 100\% = 5.05\%.
$$

$$
\Delta r_C = |r_C - r^{(0)}_C| = 94950\ \text{км}, \ \ \varepsilon_{r_C} = \frac{\Delta r_C}{r_C} \times 100\% = 5.04\%.
$$

$$
\Delta r_E = |r_E - r^{(0)}_E| = 15056\ \text{км}, \ \ \varepsilon_{r_E} = \frac{\Delta r_E}{r_E} \times 100\% = 2.24\%.
$$

$$
\Delta r_C = |r_C - r^{(0)}_C| = 43122\ \text{км}, \ \ \varepsilon_{r_C} = \frac{\Delta r_C}{r_C} \times 100\% = 2.29\%.
$$

периоды обращения спутников и ошибки их определения есть

$$
T_I = \frac{2\pi\,r_I}{V_I} = 1.859\ \text{сут}, \ \ \Delta T_I = |T_I - T^{(0)}_I| = 0.090\ \text{сут}, \ \ \varepsilon_{T_I} = \frac{\Delta T_I}{T^{(0)}_I} \times 100\% = 5.05\%.
$$

$$
T_C = \frac{2\pi\,r_C}{V_C} = 17.530\ \text{сут}, \ \ \Delta T_C = |T_C - T^{(0)}_C| = 0.841\ \text{сут}, \ \ \varepsilon_{T_C} = \frac{\Delta T_C}{T^{(0)}_C} \times 100\% = 5.04\%.
$$

$$
T_E = \frac{2\pi\,r_E}{V_E} = 3.471\ \text{сут}, \ \ \Delta T_E = |T_E - T^{(0)}_E| = 0.080\ \text{сут}, \ \ \varepsilon_{T_E} = \frac{\Delta T_E}{T^{(0)}_E} \times 100\% = 2.24\%.
$$

$$
T_C = \frac{2\pi\,r_C}{V_C} = 16.306\ \text{сут}, \ \ \Delta T_C = |T_C - T^{(0)}_C| = 0.383\ \text{сут}, \ \ \varepsilon_{T_C} = \frac{\Delta T_C}{T^{(0)}_C} \times 100\% = 2.29\%.
$$

**Ответ:** значения искомых величин представлены выше. ($\text{\textdollar}_{\max} = 14$ баллов).


</Spoiler>
