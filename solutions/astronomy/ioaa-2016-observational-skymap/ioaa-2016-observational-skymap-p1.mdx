## Условие

Mark any 5 (five) of the following stars on the map by putting a circle (O) around the appropriate star and writing its code next to it. If you mark more than 5 stars, only the first 5 in serial order will be considered.

| Code | Name | Bayer Name |
|---|---|---|
| S1 | Caph | $\beta$ Cas |
| S2 | Asellus Australis | $\delta$ Cnc |
| S3 | Acrux | $\alpha$ Cru |
| S4 | Alphard | $\alpha$ Hya |

| Code | Name | Bayer Name |
|---|---|---|
| S5 | Sheliak | $\beta$ Lyr |
| S6 | Albireo | $\beta$ Cyg |
| S7 | Rasalhague | $\alpha$ Oph |
| S8 | Kaus Australis | $\epsilon$ Sgr |
