## Условие

Приблизительно оцените зенитное расстояние Меркурия.

Ответ: __________

Estimate the approximate zenith distance of Mercury.

Answer: __________

## Решение

<Warning title="Непълно решение">
The supplied grading sheet prints the time rows but leaves the entire Mercury zenith-distance value column blank. No numerical observations are supplied.
</Warning>

<Spoiler title="Покажи официалното решение">

Zenith distance of Mercury: **5 pt**.

Mercury always stays close to the Sun, but RA of it is about $15^{\mathrm h}04^{\mathrm m}$, while RA of the Sun is $13^{\mathrm h}38^{\mathrm m}$. The combination of the knowledge of the latitude of the site, and the location of the Sun, and at the time when the observation started, it was already well below the horizon.

On October 19, the Zenith distance of Mercury was the following.

| Time | Zenith distance (degree) |
|---|---|
| 21:00 | |
| 21:15 | |
| 21:30 | |
| 21:45 | |
| 22:00 | |
| 22:15 | |
| 22:30 | |
| 22:45 | |
| 23:00 | |
| 23:15 | |

If the zenith distance at the time closest to the above table and the answer agree within 15 degree, **5 pt**.

For the additional difference at intervals of $0\text{ degree}<\text{difference}\le5\text{ degree}$ beyond the ±15 degree, -1 pt was taken off. This means that 0 pt was given if the difference is more than 35 degree.


</Spoiler>
