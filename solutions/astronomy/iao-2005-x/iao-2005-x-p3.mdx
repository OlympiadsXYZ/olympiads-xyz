## Условие

We hope that you are familiar with the object of Andromeda nebula (M31, NGC 224). Its stellar magnitude is $m=4.4^{\mathrm m}$ and its distance from us is $0.7\ \mathrm{Mpc}$. To what distance from this object should we move, if it were to shine as the full Moon? What would the (approximate) angular size of this object be in that case?

## Отговори

<Spoiler title="Покажи отговорите">

- situation is impossible - ситуация невозможна

  The native sketch prints N = exp(17.1/5) = 2630; that printed expression is retained without scientific correction.

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

The full Moon stellar magnitude is $m_M=-12.7^{\mathrm m}$. So we should come nearer to the Andromeda nebula so that the stellar magnitude changes from $m=4.4^{\mathrm m}$ to $m_M=-12.7^{\mathrm m}$, i.e. for $\Delta m=17.1^{\mathrm m}$. The formal calculation gives us $N=\exp(17.1/5)=2630$ times. $0.7\ \mathrm{Mpc}/2630\approx270\ \mathrm{pc}$. Taking into account that the angular size of the Andromeda nebula in our sky is about $2^{\circ}$–$3^{\circ}$, i.e. the linear size is about $5\cdot10^{-2}\cdot0.7\ \mathrm{Mpc}=35\,000\ \mathrm{pc}$, we see that the formal answer has no real sense. There is no real sense for the question about the angular size as well (formal answer is 130 radians).

**Answer:** «situation is impossible - ситуация невозможна».


</Spoiler>
