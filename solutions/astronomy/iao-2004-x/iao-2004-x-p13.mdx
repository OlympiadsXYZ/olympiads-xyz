## Условие

You have a sketch of sunspots for the days from January 10 to January 24, 2000. For each day determine the number of sunspots **f** and the number of groups of sunspots g, visible on this day on the solar disc. Using these data define Wolf’s number and put the results into the table:

| № | Date | Julian date | Number of spots f | Number of groups g | Wolf’s number W |
|---|---|---|---|---|---|
| 1. | | | | | |
| .. | | | | | |
| .. | | | | | |

Using the obtained results plot a graph of relation of Wolf’s number as a function of date.  
Note: Julian date for today is 2453285.

## Решение

<Spoiler title="Покажи официалното решение">

Sun. Солнце.

$W = k\cdot(10g + f)$   $k = 1$
