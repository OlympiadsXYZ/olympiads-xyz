## Условие

In the 1980s ceramic materials showing superconductivity at unusually high 90 K were discovered. Yttrium barium copper oxide (YBCO) contains Y, Ba, Cu, O. Nominal YBa₂Cu₃O₇ actually varies as YBa₂Cu₃O₇₋δ, 0 < δ < 0.5.

**4.1** Identify which circles in the idealized YBCO unit cell denote each element.

True structure is orthorhombic (a≠b≠c), approximately tetragonal with a≈b≈c/3.

**4.2** YBCO δ = 0.25 gives lowest-angle CuKα X-ray diffraction peak 2θ = 7.450°, λ = 154.2 pm. Assuming a = b = c/3, calculate a and c.

**4.3** Estimate this δ = 0.25 sample’s density in g cm⁻³. If 4.2 unsuccessful, use a = 500 pm, c = 1500 pm.

Dissolving YBCO in aqueous HCl 1.0 mol dm⁻³ releases bubbles identified as O₂ by gas chromatography. Boiling 10 min expels dissolved gases. Excess KI then gives a yellow-brown solution titratable with thiosulfate to starch endpoint. Direct addition under Ar to 1.0 mol dm⁻³ both KI/HCl gives yellow-brown solution with no gas.

**4.4** Write a balanced net ionic equation for solid YBa₂Cu₃O₇₋δ dissolving in HCl with O₂ evolution.

**4.5** Write a balanced net ionic equation for the 4.4 solution reacting with excess KI in acid after dissolved oxygen is expelled.

**4.6** Write a balanced net ionic equation for titration of 4.5 solution with thiosulfate S₂O₃²⁻.

**4.7** Write a balanced net ionic equation for solid YBa₂Cu₃O₇₋δ dissolving in HCl/excess KI under Ar.

Two identical unknown δ samples: first dissolves in 5 cm³ HCl 1.0 mol dm⁻³, evolves O₂; boil, cool, add 10 cm³ KI 0.7 mol dm⁻³ under Ar. Starch-endpoint titration consumes 1.542×10⁻⁴ mol thiosulfate. Second is added under Ar directly to 7 cm³ containing KI 1.0 mol dm⁻³/HCl 0.7 mol dm⁻³; titration consumes 1.696×10⁻⁴ mol thiosulfate.

**4.8** Calculate the Cu amount in mol in each sample.

**4.9** Calculate δ for these samples.

**4.2** sinθ = nλ/(2d). d = 154.2 pm/[2sin3.725°] = 1187 pm. Lowest angle gives longest spacing = c; c = 1187 pm, a = c/3 = 396 pm (native key repeats a = 396 pm).

**4.3** Vcell = a×b×c = 3a³ = 3(396 pm)³ = 1.863×10⁻²² cm³.

mcell = [88.91 + 2(137.33) + 3(63.55) + 6.75(16.00)]/NA = 662.22 g mol⁻¹/(6.0221×10²³ mol⁻¹) = 1.100×10⁻²¹ g.

Density = 1.100×10⁻²¹/1.863×10⁻²² = 5.90 g cm⁻³.

**4.4** YBa₂Cu₃O₇₋δ(s) + 13H⁺(aq) → Y³⁺(aq) + 2Ba²⁺(aq) + 3Cu²⁺(aq) + 0.25(1−2δ)O₂(g) + 6.5H₂O(l).

**4.5** 2Cu²⁺(aq) + 5I⁻(aq) → 2CuI(s) + I₃⁻(aq), or 2Cu²⁺(aq) + 4I⁻(aq) → 2CuI(s) + I₂(aq).

**4.6** I₃⁻(aq) + 2S₂O₃²⁻(aq) → 3I⁻(aq) + S₄O₆²⁻(aq), or I₂(aq) + 2S₂O₃²⁻(aq) → 2I⁻(aq) + S₄O₆²⁻(aq).

**4.7** YBa₂Cu₃O₇₋δ(s) + (14−2δ)H⁺(aq) + (9−3δ)I⁻(aq) → Y³⁺(aq) + 2Ba²⁺(aq) + 3CuI(s) + (7−δ)H₂O(l) + (2−δ)I₃⁻(aq), or YBa₂Cu₃O₇₋δ(s) + (14−2δ)H⁺(aq) + (7−2δ)I⁻(aq) → Y³⁺(aq) + 2Ba²⁺(aq) + 3CuI(s) + (7−δ)H₂O(l) + (2−δ)I₂(aq).

**4.8** n(Cu) = n(thiosulfate) in first titration = 1.542×10⁻⁴ mol.

**4.9** Total Cu 1.542×10⁻⁴ mol; CuIII = (1.696−1.542)×10⁻⁴ = 1.54×10⁻⁵ mol; 90% CuII, 10% CuIII. Charge balance:

2(7−δ) = 3 + 2(2) + 3[0.90(2) + 0.10(3)] = 13.30; δ = 0.35.

Alternatively, using balanced equations in (d): first titration each mole YBCO corresponds 1.5 mol I₃⁻/3 mol S₂O₃²⁻; second corresponds (2−δ) mol I₃⁻/(4−2δ) mol S₂O₃²⁻.

1.542×10⁻⁴ / 1.696×10⁻⁴ = 3/(4−2δ) = 1.5/(2−δ); 2−δ = 1.650; δ = 0.35.
