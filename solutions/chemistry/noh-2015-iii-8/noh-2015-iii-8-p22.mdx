## Условие

**ЗАДАЧА 2.**

**Веществото (А) е безцветна, маслообразна течност. При определени условия тя се разлага. Един от продуктите на разлагането – (Б) може да се получи и при взаимодействие на веществото (В) с водород.**

**Зависимостта между величините – количество вещество и маса за простото вещество (В), е представена на фиг.1**

**1)** Като използвате графиката, определете кое е веществото (В) и запишете химичната му формула. Отговора си подкрепете със съответните изчисления. **[3 т.]**

**2)** Изразете с химични уравнения разлагането на веществото (А) и получаването на (Б) от (В). **[6 т.]**

**Веществото (Б) реагира с $\mathrm{K_2O}$, като се образува съединението (Г). При реакция между (А) и (Г) се образува (Д), което с бариева основа образува бяла утайка – (Е).**

**3)** Изразете с химични уравнения посочените реакции и назовете веществото (Д). **[10 т.]**

**4)** Как се нарича реакцията, по която се получава веществото (Д)? **[1 т.]**

## Отговори

<Spoiler title="Покажи отговорите">

- **1)** O₂
- **3)** (Д) – дикалиев сулфат, $\mathrm{K_2SO_4}$
- **4)** неутрализация

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

| Отговори | Точки |
| --- | --- |
| 1) $M(\mathbf{В}) = m(\mathbf{В})/n(\mathbf{В})$ | 1) 1 + 2 = **3 т.** |
| Например: $M(\mathbf{В}) = 32/1 = 32\ \mathrm{g/mol}$ |  |
| От посочените свойства на (А) и (В) => (В) е $\mathrm{O_2}$ |  |
| 2) $\mathrm{k.H_2SO_4 \xrightarrow{t} H_2O + SO_2\uparrow + O}$ | 2) 2 × 3 т = **6 т.** |
| $\mathrm{2\ H_2 + O_2 \xrightleftharpoons{t} 2\ H_2O}$ |  |
| (А) – $\mathrm{H_2SO_4}$, (Б) – $\mathrm{H_2O}$ |  |
| 3) $\mathrm{K_2O + H_2O \rightarrow 2\ KOH}$ (Г) | **3) 10 т.** |
| $\mathrm{2\ KOH + H_2SO_4 \rightarrow 2\ H_2O + K_2SO_4}$ (Д) | 3 x 3 т = 9 т |
| $\mathrm{K_2SO_4 + Ba(OH)_2 \rightarrow 2\ KOH + BaSO_4\downarrow}$ (Е) |  |
| (Д) – дикалиев сулфат | 1 т. |
| 4) неутрализация | **4) 1 т.** |
|  | **Макс: 20 т.** |


</Spoiler>
