*Подборен кръг за XVII-то Национално състезание по химия и опазване на околната среда – 12. 03. 2015 г. · 12 март 2015 г. · 7 т.*

## Условие

Етанолът намира приложение в медицината фармацията, козметиката.

**А)** Предложете 3 различни промишлени метода за получаване на етанол. **[3 т.]**

**Б)** В три епруветки има разтвори на етанол, глицерол и яйчен белтък. Как ще ги разпознаете експериментално? Попълнете таблицата.

| Разтвор | Реактив | Наблюдавани промени |
|---|---|---|
| етанол | | |
| глицерол | | |
| яйчен белтък | | |

**[3 т.]**

**В)** В лабораторни условия етанолът се използва за получаване на етен. Изразете с уравнение взаимодействието. **[1 т.]**

## Решение

<Spoiler title="Покажи официалното решение">

**А)** За 3 различни промишлени метода за получаване на етанол **3x1 т. = 3 т.**

$\mathrm{H_2C{=}CH_2 + H_2O} \xrightarrow{+H^{+},\ t^{\circ}\mathrm{C}} \mathrm{CH_3CH_2OH}$

$\mathrm{HC{\equiv}CH + H_2O} \xrightarrow{+Hg^{2+},H_2SO_4,\ t^{\circ}\mathrm{C}} \mathrm{CH_3CHO} \xrightarrow{H_2,\ \mathrm{Ni},\ \mathrm{p},\ t^{\circ}\mathrm{C}} \mathrm{CH_3CH_2OH}$

$\mathrm{C_6H_{12}O_6} \xrightarrow{\text{цимаза}} \mathrm{2\,CH_3CH_2OH + 2\,CO_2}$

**Б)** 6 x 0,5 т. = **3 т.**

**В)** $\mathrm{CH_3CH_2OH} \xrightarrow{\mathrm{k.}H_2SO_4,\ t > 140\ {}^{\circ}\mathrm{C}} \mathrm{H_2C{=}CH_2 + H_2O}$ **1 т.**


</Spoiler>
