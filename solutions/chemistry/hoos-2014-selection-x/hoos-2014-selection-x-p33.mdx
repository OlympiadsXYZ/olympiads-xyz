## Условие

Химичното съединение **А** е широко разпространено в природата и неразтворимо във вода. При нагряване то се разлага до съединенията **Б** и **В**. **Б** взаимодейства с вода и образува съединението **Г**, чиито воден разтвор променя цвета на фенолфталейна в малиновочервено. **Б** и **Г** взаимодействат с газа **В** и образуват **А**, а при взаимодействието им със солна киселина се получава съединението **Д**. **Д** внесено в пламъка на лампата го оцветява в керемиденочервено.

**А)** Кои са веществата **А**, **Б**, **В**, **Г** и **Д** ? Запишете формули и наименования. **[2,5 т.]**

**Б)** Изразете по подходящ начин означените взаимодействия. Определете вида на процесите.

**А** $\longrightarrow$ **Б** + **В**

**Б** + $\mathrm{H_2O}$ $\longrightarrow$

**Г** + **В** $\longrightarrow$

**Б** + HCl $\longrightarrow$

**Г** + HCl $\longrightarrow$ **[8 т.]**

**В)** Какъв е характера на водния разтвор на веществото **Д**? **[1 т.]**

**Г)** Изразете взаимодействие с участие на съединението **А**, при което се оформя релефа на земята. **[1 т.]**

**Д)** Изразете равновесната константа на процеса на разлагане на веществото **А**. **[1 т.]**

## Отговори

<Spoiler title="Покажи отговорите">

- **А)** А – CaCO₃ (калциев карбонат); Б – CaO (калциев оксид); В – CO₂ (въглероден диоксид); Г – Ca(OH)₂ (калциева основа); Д – CaCl₂ (калциев дихлорид)
- **Д)** $K_c = c(\mathrm{CO_2})$

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

А) за веществата **А**, **Б**, **В**, **Г** и **Д** **5х(2х0,25 т.) = 2,5 т.**

| | | |
|---|---|---|
| **А** | $\mathrm{CaCO_3}$ | калциев карбонат |
| **Б** | CaO | калциев оксид |
| **В** | $\mathrm{CO_2}$ | въглероден диоксид |
| **Г** | $\mathrm{Ca(OH)_2}$ | калциева основа |
| **Д** | $\mathrm{CaCl_2}$ | калциев дихлорид |

Б) - за химичните уравнения **4х1 т.+ 1,5 т. = 5,5 т.**

- за вида на процесите **5х0,5 т. = 2,5 т.**

| | | |
|---|---|---|
| **А** $\longrightarrow$ **Б** + **В** | $\mathrm{CaCO_3 \rightleftharpoons CaO + CO_2}$ | без преход на електрони |
| **Б** + $\mathrm{H_2O}$ $\longrightarrow$ | $\mathrm{CaO + H_2O \longrightarrow Ca(OH)_2}$ | без преход на електрони |
| **Г** + **В** $\longrightarrow$ | $\mathrm{Ca(OH)_2 + CO_2 \longrightarrow CaCO_3 + H_2O}$ | без преход на електрони |
| **Б** + HCl $\longrightarrow$ | $\mathrm{CaO + 2\ HCl \longrightarrow CaCl_2 + H_2O}$ | без преход на електрони |
| **Г** + HCl $\longrightarrow$ | $\mathrm{Ca(OH)_2 + 2\ HCl \longrightarrow CaCl_2 + 2\ H_2O}$ | йоннообменен |

*(пълно и съкратено йонно уравнение)*

В ) основен $\mathrm{Ca(OH)_2 \longrightarrow Ca^{2+} + 2\ OH^{-}}$ **1 т.**

Г) $\mathrm{CaCO_3 + CO_2 + H_2O \rightleftharpoons Ca(HCO_3)_2}$ **1 т.**

Д) $K_c = c(\mathrm{CO_2})$ **1 т.**


</Spoiler>
