*Първата част съдържа* ***30*** *задачи с по 4 отговора, само един от които е верен. Отбележете го с хикс – „Х“ в приложената таблица. Не се допускат поправки и задрасквания в таблицата за отговори.*

*Втората част се състои от 10 задачи със свободен отговор. При решаването им спазвайте указанията и отговаряйте точно, кратко и ясно.*

## Условие

Дадени са веществата: кислород, водороден пероксид, амоняк, амониев йодид.

**А)** Определете вида на всички химични връзки в дадените вещества и отбележете със знака „+ “ в таблицата:

| **Вещество** | **Донорно-акцепторна връзка** | **Ковалентна химична връзка** | **Проста** | **Сложна** | **Неполярна** | **Полярна** | **Йонна химична връзка** |
|---|---|---|---|---|---|---|---|
| Водороден пероксид | | | | | | | |
| Амониев йодид | | | | | | | |
| Амоняк | | | | | | | |

**[3 т.]**

**Б)** Означете с люисови формули образуването на химични връзки в: $\mathbf{O_2}$, $\mathbf{NH_3}$. **[2 т.]**

**В)** Как експериментално може да се докаже съставът на солта $\mathbf{NH_4I}$? Подберете реактиви и означете процесите с подходящи уравнения. **[4 т.]**

## Решение

<Spoiler title="Покажи официалното решение">

А) За всеки верен хоризонтален ред **- 1т** **3х1 т. = 3 т.**

*За непълен отговор – по 0,5 т.*

| **Вещество** | **Донорно-акцепторна връзка** | **Ковалентна химична връзка** | **Проста** | **Сложна** | **Неполярна** | **Полярна** | **Йонна химична връзка** |
|---|---|---|---|---|---|---|---|
| Водороден пероксид | | + | + | | + | + | |
| Амониев йодид | + | + | + | | | + | + |
| Амоняк | | + | + | | | + | |

Б) за означаване с люисови формули образуването на химични връзки в: $\mathbf{O_2}$, $\mathbf{NH_3}$. **2х1 т. = 2 т.**

В) – за избор на реактиви **2х0,5 т. = 1 т.**

- за химичните уравнения (молекулно, пълно йонно, съкратено йонно) **2х(0,5т. + 0,5т. +0,5т.) = 3 т.**


</Spoiler>
