## Условие

Дадена е схемата:

**А** + HCl $\longrightarrow$ **Б** + $\mathrm{H_2O}$

**Б** + 2Na + хлороетан $\longrightarrow$ 2-метилбутан

**А** + $\mathrm{CH_3COOH}$ $\rightleftharpoons$ **В** + $\mathrm{H_2O}$

**А)** Кои са веществата **А**, **Б** и **В**?

| **Вещества** | **А** | **Б** | **В** |
|---|---|---|---|
| **Формула** | | | |
| **Наименование** | | | |

**[3 т.]**

**Б)** Изразете реакциите с химични уравнения. **[3 т.]**

**В)** Означете с уравнения два метода за получаване на веществото **А**. **[2 т.]**

## Отговори

<Spoiler title="Покажи отговорите">

- **А)** А – CH₃CH(OH)CH₃ (2-пропанол); Б – CH₃CH(Cl)CH₃ (2-хлоропропан); В – CH₃COOCH(CH₃)₂ (изопропилацетат)

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

А) за веществата **А**, **Б** и **В**: **6х0,5 т. = 3 т.**

| **Вещества** | **А** | **Б** | **В** |
|---|---|---|---|
| Формула | $\mathrm{CH_3CH(OH)CH_3}$ | $\mathrm{CH_3CH(Cl)CH_3}$ | $\mathrm{CH_3COOCH(CH_3)_2}$ |
| Наименование | 2-пропанол | 2-хлоропропан | изопропилацетат |

Б) за уравненията **3х1 т. = 3 т.**

$\mathrm{CH_3CH(OH)CH_3 + HCl \longrightarrow CH_3CH(Cl)CH_3 + H_2O}$

$\mathrm{CH_3CH(Cl)CH_3 + 2Na + C_2H_5Cl \xrightarrow{\text{етер}} 2\ NaCl + CH_3CH(CH_3)CH_3}$

$\mathrm{CH_3CH(OH)CH_3 + CH_3COOH \rightleftharpoons CH_3COOCH(CH_3)_2 + H_2O}$

В) за два метода за получаване на веществото $\mathrm{CH_3CH(OH)CH_3}$ **2х1 т. = 2 т.**


</Spoiler>
