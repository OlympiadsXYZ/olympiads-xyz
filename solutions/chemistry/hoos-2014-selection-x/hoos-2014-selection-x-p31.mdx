## Условие

Дадена е таблицата:

| **Формула** | Грамове разтворено **БЕЗВОДНО** вещество в 100g $\mathrm{H_2O}$ при $t^{0}$C | | | | | | | | |
|---|---|---|---|---|---|---|---|---|---|
| | $0^{0}$ | $10^{0}$ | $20^{0}$ | $30^{0}$ | $40^{0}$ | $50^{0}$ | $60^{0}$ | $70^{0}$ | $80^{0}$ |
| $\mathrm{AgNO_3}$ | 122 | 170 | 222 | 300 | 376 | 455 | 525 | - | 669 |

**А)** Въз основа на данните от таблицата определете знака на топлинния ефект на процеса на разтваряне на сребърния нитрат във вода. Обосновете се! **[2 т.]**

**Б)** Изчислете масовата част ($\boldsymbol{w}$) на разтвореното вещество в наситения разтвор при 30°C. **[2 т.]**

## Отговори

<Spoiler title="Покажи отговорите">

- **А)** Топлинният ефект на разтварянето е отрицателен, −Q
- **Б)** 0.75

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

А) - *Топлинният ефект на разтварянето е отрицателен,* **- *Q*** **1 т.**

- *за обосновка* **1 т.**

Б) $w(AgNO_3) = \dfrac{m(AgNO_3)}{m} = \dfrac{300}{300+100} = 0{,}75$ или 75% **2 т.**


</Spoiler>
