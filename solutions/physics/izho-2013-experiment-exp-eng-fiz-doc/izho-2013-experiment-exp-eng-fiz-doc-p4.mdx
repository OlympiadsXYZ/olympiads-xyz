## Условие

Direct the laser beam on the hole with the plastic orange element. This element has a three-dimensional structure. Place the screen behind this element, you should see a number of bright spots in the transmitted light.

**4.1** Make a guess on the structure of this element that could explain the observed pattern of the reflected beams.

**4.2** Estimate the refractive index of the material from which this optical element is made of.
