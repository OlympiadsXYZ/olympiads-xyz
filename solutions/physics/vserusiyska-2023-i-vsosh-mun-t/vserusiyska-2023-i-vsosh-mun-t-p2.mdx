## Условие

<figure className="problem-figure problem-figure--sized" style={{'--fig-w': '37.5%', '--fig-max': '240px'}}>

С помощью пиксельного рисунка определите высоту привидения $H$, выраженную в миллиметрах. Известно, что рисунок сделан с разрешением 300 dpi, то есть 300 пикселей на дюйм.

*Примечание:* пиксель – это минимальный и неделимый элемент (квадрат), из которого состоит изображение. 1 дюйм = 2,54 см.

## Отговори

<Spoiler title="Покажи отговорите">

- 3 мм

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

**Решение.**

Найдем чему равна высота изображения $H$, выраженная в пикселях. Для этого посчитаем количество квадратов:

$$
H = 37\ \text{пикселей}
$$

<figure className="problem-figure problem-figure--sized" style={{'--fig-w': '37.9%', '--fig-max': '243px'}}>
<img src="https://pub-43290baaaff14857b5dd59610ea438c7.r2.dev/problems/vserusiyska-2023-i-vsosh-mun-t/p2-sol-fig1-v2.png" alt="Тот же пиксельный рисунок привидения, что и в условии: вертикальная стрелка H — высота рисунка, выноска «1 пиксель»." width="760" height="653" loading="lazy" decoding="async" />
</figure>

Составим пропорцию и найдем высоту H, выраженную в дюймах:

$$
\frac{300\ \text{пикслей}}{1\ \text{дюйм}} = \frac{37\ \text{пикселей}}{H};
$$

$$
H \approx 0{,}12\ \text{дюймов} = 0{,}12\times 2{,}54 \approx 0{,}3\ \text{см} = 3\ \text{мм}.
$$

**Критерии оценивания.**

| | | | |
|---|---|---|---|
| 1 | | Высота изображения $H$, выраженная в пикселях | 2 |
| 2 | | Перевод высоты $H$ в дюймы (или количества пикселов в единицы длины) | 3 |
| 3 | | Перевод высоты $H$ в см (мм, м) (или любой перевод дюймов в метрические единицы)) | 3 |
| 4 | | Численно верный ответ | 2 |
| | Итого: | | 10 |

*Примечание:* В п.1 допустима ошибка +- 1 пиксель (36 - 38 пикселей).

п. 2 и 3 могут быть объединены в одно действие.

В п.4 за накопленную погрешность не нужно снимать баллы
