## Условие

Кусочек масла объёмом 10 мл ползёт по лезвию раскалённого ножа со скоростью $\dfrac{5}{7}$ см/с. Длина лезвия 30 см. Масло, двигаясь по горячему, потихоньку тает с массовым расходом $\mu = \dfrac{3}{14}$ г/с. Плотность масла 900 кг/м$^3$. Что кончится раньше: нож или масло? Определите массовый расход масла на единицу пути.

## Отговори

<Spoiler title="Покажи отговорите">

- Закончатся одновременно (через 42 с). Массовый расход масла на единицу пути 0,3 г/см.

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

**ОТВЕТ:** закончатся одновременно (через 42 с). Массовый расход масла на единицу пути 0,3 г/см.

**Возможное решение:**

Масса масла $m = \rho V = 9$ г.

Время плавления масла $t = \dfrac{m}{\mu} = \dfrac{9}{3/14} = 42c$

Время скольжения $t = \dfrac{S}{\upsilon} = \dfrac{30}{5/7} = 42c$

Оба процесса закончатся одновременно.

$$
\alpha = \frac{\Delta m}{S} = \frac{9\text{г}}{30\text{см}} = 0{,}3\frac{\text{г}}{\text{см}}
$$

Массовый расход за единицу пути: *или*

$$
\alpha = \frac{\mu}{\upsilon} = 0{,}3\frac{\text{г}}{\text{см}}
$$

**Критерии оценивания.**

| | | |
|---|---|---|
| | Найдена масса тела | 2 |
| | Найдено время плавления масла | 2 |
| | Найдено время время скольжения | 2 |
| | Сделан вывод о равенстве времён | 1 |
| | Найден массовый расход α | 3 |
| | ИТОГ | 10 |


</Spoiler>
