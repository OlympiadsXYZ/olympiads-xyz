How many bits of information did you receive after having read the problems of a YPT? [32] How many bits of information would you receive when looking at a geographic map with the size of a paper sheet? [33]

<ProblemSection id="note-32">

### Note [32]

The Kvant version read: “How much information (in bits) did you receive after having read these tasks of the Correspondence Round?” The 1996 Czech version read: “How many bits of information you have received when reading these tasks?” The 2006 English version read: “How many bits information have you obtained by reading this question?”

</ProblemSection>

<ProblemSection id="note-33">

### Note [33]

The Kvant version read: “How much information (in bits) you would receive when looking on a geographic map with a size of a one page of text?” The 1996 Czech version read: “How many bits of information you would receive when looking on a one-page geographic map?” The 2006 English version read: “How many bits you obtain with view of a plane geographical map?” The Slovak version reads: “How many bits of information you would receive when looking on a geographic map with the size A4?”

</ProblemSection>
