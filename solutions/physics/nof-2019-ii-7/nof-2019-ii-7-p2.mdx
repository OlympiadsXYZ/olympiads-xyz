*Олимпиада по физика 2019, областен кръг, тема за 7. клас (първа състезателна група) · 5 февруари 2019 г. · 10 т.*

## Условие

Два консуматора със съпротивления съответно $R_1 = 2\ \Omega$ и $R_2 = 3\ \Omega$ участват във верига с $n$ на брой последователно свързани еднакви източника, всеки с напрежение $U_0 = 1{,}5\ \mathrm{V}$. Във веригата има включен автоматичен прекъсвач със схемен знак $-\boxed{\Pi}-$, който се задейства и прекъсва веригата при протичане на ток, по-голям от $5\ \mathrm{A}$.

**а)** Начертайте схемите на електрическата верига при последователно свързване и при успоредно свързване на консуматорите. **[2 т.]**

**б)** Какъв максимален брой източници може да се свържат последователно, без да се задейства прекъсвачът, ако във веригата двата консуматора са свързани:

**А)** последователно **[5 т.]**

**Б)** успоредно **[3 т.]**

## Отговори

<Spoiler title="Покажи отговорите">

- **А)** $I = \frac{nU_0}{R_1+R_2} = n\cdot 0{,}3\ \mathrm{A} \le 5\ \mathrm{A} \Rightarrow n \le 16{,}7 \Rightarrow n = 16$
- **Б)** $I = nU_0\left(\frac{1}{R_1}+\frac{1}{R_2}\right) = n\frac{7{,}5}{6}\ \mathrm{A} \le 5\ \mathrm{A} \Rightarrow n \le 4$

</Spoiler>

## Решение

**а)** За всяка фигура по : фиг. 2 **[1 т.]**, фиг. 3 **[1 т.]**

**б)** Напрежението на последователно свързаните източници е $U = nU_0$. **[1 т.]**

**А)** При последователно свързване на консуматорите (фиг. 2) през тях и през автоматичния превключвател тече един и същ ток $I$, като $U = U_1 + U_2$, **[1 т.]** $U_1 = IR_1$, $U_2 = IR_2$. **[1 т.]**

След заместване намираме $I = \dfrac{nU_0}{R_1+R_2} = n.0{,}3\ \mathrm{A}$. **[1 т.]**

От условието $I \le 5\ \mathrm{A}$ следва $n \le \dfrac{5}{0{,}3} \approx 16{,}7$. Тъй като $n$ е цяло число, имаме $n = 16$. **[1 т.]**

**Б)** При успоредно свързване (фиг. 3) токовете през консуматорите са съответно $I_1 = \dfrac{nU_0}{R_1}$, $I_2 = \dfrac{nU_0}{R_2}$. **[1 т.]**

Токът във веригата, т. е. токът, който тече през автоматичния превключвател, е $I = I_1 + I_2 = nU_0\left(\dfrac{1}{R_1}+\dfrac{1}{R_2}\right) = n\dfrac{7{,}5}{6}\ \mathrm{A}$. **[1 т.]**

От условието $I \le 5\ \mathrm{A}$ следва $n \le \dfrac{30}{7{,}5} = 4$. Така максималният брой последователно свързани източници, при който превключвателят няма да прекъсне веригата, е $n = 4$. **[1 т.]**
