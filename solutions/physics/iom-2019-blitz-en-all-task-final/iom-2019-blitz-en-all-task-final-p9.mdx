## Условие

A given solution (pH $\approx$ 7) contains several ions with the concentrations listed in the table.

| Ion | Concentration (mM) |
| --- | --- |
| Potassium $K^{+}$ | 22 |
| Magnesium $Mg^{2+}$ | 44 |
| Sodium $Na^{+}$ | 66 |
| Carbonate $CO_3^{2-}$ | 44 |
| Nitrate $NO_3^{-}$ | 66 |
| Chloride $Cl^{-}$ | ? |

What is the concentration of chloride ions in the solution (in mM)? Give the integer answer without units.
