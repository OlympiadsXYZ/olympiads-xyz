*The Blitz-contest of IOM-2021*

## Условие

Messages that are transferred over a communication channel contain only four letters P, О, S, Т; binary code is used for transferring, it allows unambiguous decoding. Code words for letters Т, О and P are respectively Т: 111, О: 0, Р: 011. What is the shortest code word for the letter S if the code always allows the unambiguous decoding? If there are several codes, select the code with the smallest numerical value.
