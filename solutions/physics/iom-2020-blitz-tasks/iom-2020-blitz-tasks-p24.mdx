*The Blitz-contest of IOM-2020*

## Условие

$$
\begin{array}{l}\texttt{int binary\_search(vector<int> vec, int value, int n)\{}\\ \quad \texttt{sort(vec.begin(),vec.end());}\\ \quad \texttt{int l = 0, r = n – 1}\\ \quad \texttt{while (l <= r)\{}\\ \qquad \texttt{int mid = (l + r) / 2;}\\ \qquad \texttt{if (vec[mid] <= l)}\\ \qquad\quad \texttt{l = mid;}\\ \qquad \texttt{else}\\ \qquad\quad \texttt{r = mid;}\\ \quad \texttt{\}}\\ \quad \texttt{return l;}\\ \texttt{\}}\end{array}
$$

Determine the time complexity of the function above

- $O(N)$
- $O(logN)$
- $O(NlogN)$
- $O(Nlog^2N)$
- $O(\infty)$
