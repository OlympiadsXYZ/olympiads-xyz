*The Blitz-contest of IOM-2020*

## Условие

Given the following binary search algorithm:

$$
\begin{array}{l}\texttt{int X, L, R, c;}\\ \texttt{L = 0; R = N;}\\ \texttt{while ( L < R-1 )}\\ \quad \texttt{\{}\\ \quad \texttt{c = (L+R) / 2;}\\ \quad \texttt{if ( X < A[c] )}\\ \qquad\quad \texttt{R = c;}\\ \quad \texttt{else L = c;}\\ \quad \texttt{\}}\\ \texttt{if ( A[L] == X )}\\ \qquad \texttt{cout << "A[" << L << "]=" << X << endl;}\\ \texttt{else cout << -1 << endl;}\end{array}
$$

How many comparisons will be made if we are looking for an element that is not in the array. Sorted array length $N$ is 10.
