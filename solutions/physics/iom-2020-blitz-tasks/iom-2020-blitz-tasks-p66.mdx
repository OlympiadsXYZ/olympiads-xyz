*The Blitz-contest of IOM-2020*

## Условие

For storing an arbitrary 128$\times$320 bitmap pixels allocated 50 kibibytes (KiB) of memory without taking into account the size of the file header. For colour encoding each pixel uses the same amount bits, pixel codes are written to the file one by one without gaps. What is the maximum number of colours that can be used in an image?

## Отговори

<Spoiler title="Покажи отговорите">

- 1024

</Spoiler>
