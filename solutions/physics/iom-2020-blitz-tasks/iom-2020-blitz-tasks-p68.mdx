*The Blitz-contest of IOM-2020*

## Условие

We are given a set $S$ which contains only elements $0$ and $95$ at the beginning. At each step we add elements to $S$ according to the following rule: We choose a non-constant polynomial whose all coefficients are in $S$, and add all its integer roots to $S$. What is the maximal number of elements that $S$ can have after finitely many such steps?
