*ВСЕРОССИЙСКАЯ ОЛИМПИАДА ШКОЛЬНИКОВ ПО ФИЗИКЕ. МУНИЦИПАЛЬНЫЙ ЭТАП. 2023-2024 учебный год · 10 т.*

## Условие

Экспериментатор Глюк и теоретик Баг налили себе в стаканы по 100 г горячего чая, имеющего температуру $\mathrm{T}_{100} = 100^{\circ}\mathrm{C}$. Для охлаждения чая у них в запасе имелось большое ведро воды при температуре $\mathrm{T}_0 = 0^{\circ}\mathrm{C}$.

Глюк опускал на ниточке монетку теплоёмкостью $C_1 = 7{,}82$ Дж/℃ сначала в ведро, потом в стакан с чаем, всё время дожидаясь установления теплового равновесия. Этот алгоритм он повторил 10 раз.

Баг просто добавил в свой стакан холодную воду из ведра массой $m_2 = 18{,}0$ г и дождался установления теплового равновесия.

Определите кто из друзей сильнее охладил свой чай.

Удельная теплоемкость чая и воды $\mathrm{c}_{\text{в}} = 4200\,\frac{\text{Дж}}{\text{кг}\ {}^{\circ}\mathrm{C}}$.

Теплообменом с окружающей средой, изменением температуры воды в ведре и теплоемкостью стаканов можно пренебречь, чай из стакана не выливался.

## Отговори

<Spoiler title="Покажи отговорите">

- Сильнее охладил чай Глюк: $T_1 = 83{,}2$ °C, у Бага $T_2 = 84{,}7$ °C.

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

**8.3.Двойное охлаждение. (Кузнецова А.В.)**

**Возможное решение:**

Запишем уравнение теплового баланса для процесса Бага:

$$
m_2 c_2 (T_2 - T_0) = M c_2 (T_{100} - T_2)
$$

$$
T_2 = 84{,}7\ {}^{\circ}\mathrm{C}
$$

Запишем уравнение теплового баланса для одной итерации охлаждения Глюка:

$$
\mathrm{C}_1 (T_{x1} - T_0) = M c_2 (T_{100} - T_{x1})
$$

$$
T_{x1} = \frac{T_{100}}{\left(1 + \frac{\mathrm{C}_1}{M c_2}\right)}
$$

Для нахождения температуры после второй итерации $T_{x2}$ получится аналогичное уравнение, только начальная температура чая будет $T_{x1}$, а не $T_{100}$. Значит, итоговое выражение для температуры чая в стакане Глюка после 10 циклов:

$$
T_1 = \frac{T_{100}}{\left(1 + \frac{\mathrm{C}_1}{M c_2}\right)^{10}} = 83{,}2\ {}^{\circ}\mathrm{C}
$$

Чай Глюка охладился сильнее.

**Критерии оценивания**

| № | Критерий | Балл |
|---|---|---|
|  | Записано уравнение теплового баланса для процесса Бага | 1 |
|  | Получено выражение для температуры чая Бага после охлаждения | 1 |
|  | Найдена конечная температура чая Бага $T_2 = 84{,}7\ {}^{\circ}\mathrm{C}$ | 1 |
|  | Записано уравнение теплового баланса для одной итерации охлаждения Глюка | 2 |
|  | Получено выражение для температуры после первого цикла: $T_{x1} = \frac{T_{100}}{\left(1 + \frac{m_1 c_1}{M c_2}\right)}$ | 1 |
|  | Получено выражение для температуры после десяти итераций: $T_1 = \frac{T_{100}}{\left(1 + \frac{m_1 c_1}{M c_2}\right)^{10}}$ | 2 |
|  | Вычислена температура: $T_1 = 83{,}2\ {}^{\circ}\mathrm{C}$ | 1 |
|  | Сделан вывод о том, что Глюк охладил чай сильнее | 1 |
|  | **max** | **10,0** |
