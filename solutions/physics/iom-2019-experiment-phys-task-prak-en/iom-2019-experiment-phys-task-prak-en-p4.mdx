## Условие

Compare the value of $p_0$ obtained in exercise 1.3 with the atmospheric pressure $p_a$ written on the blackboard in the classroom. Do these values coincide? Should the <u>precisely measured</u> value of $p_0$ coincide with the atmospheric pressure? If you believe there should be a discrepancy, explain the reason behind it in a few words in English or Russian.
