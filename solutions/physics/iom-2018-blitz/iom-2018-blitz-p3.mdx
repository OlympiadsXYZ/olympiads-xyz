*OLYMPIAD OF METROPOLISES. Moscow, September 3 · 3 септември 2018 г.*

## Условие

Below you see a list of statements about server technologies. Choose the correct statements.

1) RAID (Redundant Array of Inexpensive Disks) is a storage system especially designed for servers and doesn’t work anymore if one of the disks fails.
2) Port scanning can be used to determine active services in a system because most of them are running on documented standard ports.
3) HTML is the common markup language for structuring the layout of a website and determining how servers communicate with the client.
4) HTTP is the only protocol for file transmission between the client and the server.

## Отговори

<Spoiler title="Покажи отговорите">

- 2

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

Answer: 2


</Spoiler>
