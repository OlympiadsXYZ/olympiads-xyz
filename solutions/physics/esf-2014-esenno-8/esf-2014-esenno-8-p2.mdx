*Национално есенно състезание по физика 2014, тема за 8. клас · 8 ноември 2014 г. · 10 т.*

## Условие

Консуматор със съпротивление $R$ е включен към източник, при което токът във веригата е $I$. Възможно е свързване на допълнителен консуматор във веригата, при което токът във веригата се променя с $\eta$ част от първоначалния ток $I$, като $\eta < 1$.

**а)** Какво съпротивление $R_1$ трябва да има консуматор, който се свързва последователно на първоначалния при изброените условия? **[4 т.]**

**б)** Какво трябва да бъде съпротивлението $R_2$ на консуматор, който се свързва успоредно на първоначалния? **[4 т.]**

**в)** На колко е равна общата мощност на консуматорите $P_1$ при последователно свързване и $P_2$ при успоредно свързване? **[2 т.]**

## Отговори

<Spoiler title="Покажи отговорите">

- **а)** $R_1 = \dfrac{\eta}{1-\eta}R$
- **б)** $R_2 = \dfrac{1}{\eta}R$
- **в)** $P_1 = (1-\eta)P,\qquad P_2 = (1+\eta)P$

</Spoiler>

## Решение

**а)** При последователно свързване общото съпротивление $R_1 + R > R$ **[0,5 т.]**, при което токът $I_1 < I$ **[0,5 т.]**, като

$$I_1 = (1-\eta)I.$$

**[1 т.]**

От друга страна имаме $I = U/R$, при което можем да запишем

$$I_1 = \frac{U}{R_1 + R} = \frac{I}{(R_1/R) + 1} = (1-\eta)I.$$

**[1 т.]**

Тогава получаваме

$$R_1 = \frac{\eta}{1-\eta}R.$$

**[1 т.]**

**б)** При успоредно свързване общото съпротивление $R_2R/(R_2 + R) < R$ **[0,5 т.]**, при което токът $I_2 > I$ **[0,5 т.]**, като

$$I_2 = (1+\eta)I.$$

**[1 т.]**

От друга страна имаме

$$I_2 = \frac{U}{R_2R/(R_2+R)} = \frac{I[(R_2/R)+1]}{R_2/R} = (1+\eta)I.$$

**[1 т.]**

Тогава получаваме

$$R_2 = \frac{1}{\eta}R.$$

**[1 т.]**

**в)** В случая на последователно свързване мощността на консуматорите във веригата е

$$P_1 = I_1^2(R_1 + R) = (1-\eta)P,$$

**[1 т.]**

докато при успоредно свързване на консуматорите имаме

$$P_2 = I_2^2\,\frac{R_2R}{R_2+R} = (1+\eta)P,$$

**[1 т.]**

където $P = I^2R$ е мощността на консуматора, включен първоначално във веригата.
