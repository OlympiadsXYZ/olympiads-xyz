*OLYMPIAD OF METROPOLISES. Moscow, September 4 · 4 септември 2017 г.*

## Условие

Look through the following algorithm:

1. INPUT n
2. PRINT n
3. IF n = 1 THEN STOP
4. IF n is odd THEN n = 3n + 1
5. ELSE n = n/2
6. GOTO 2

How many numbers will be outputted if input is 22?

## Отговори

<Spoiler title="Покажи отговорите">

- 16

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

Answer: 16


</Spoiler>
