*OLYMPIAD OF METROPOLISES. Moscow, September 4 · 4 септември 2017 г.*

## Условие

In The Nine Chapters on the Mathematical Art, a Chinese mathematics book composed by several generations of scholars from the 10th - 2nd century BCE, an algorithm called “Subtracting Each Other Technique” was recorded. Here is an implementation of this algorithm in Visual Basic.

<figure className="problem-figure problem-figure--sized" style={{'--fig-w': '66%', '--fig-max': '423px'}}>
<img src="https://pub-43290baaaff14857b5dd59610ea438c7.r2.dev/problems/iom-2017-blitz/p11-fig1.png" alt="Visual Basic listing: Private Sub Command1_Click(); Dim a,b,c,r,t As Integer; a = Val(InputBox('Input The First Number')); b = Val(InputBox('Input The Second Number')); c = 0; Do While a Mod 2 = 0 And b mod 2 = 0: a = a / 2, b = b / 2, c = c + 1, Loop; Do While a <> b: If a < b Then t = a, a = b, b = t, End If; r = a - b; a = b; b = r; Loop; Print r*2^c; End Sub." width="1321" height="1093" loading="lazy" decoding="async" />
</figure>

Provide the output of the program after entering two numbers,
a = 98 and b = 63.

## Отговори

<Spoiler title="Покажи отговорите">

- 7

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

Answer: 7


</Spoiler>
