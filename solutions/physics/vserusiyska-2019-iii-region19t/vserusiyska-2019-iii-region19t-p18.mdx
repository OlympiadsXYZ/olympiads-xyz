*LIII Всероссийская олимпиада школьников по физике. Региональный этап. Теоретический тур. 21 января 2019 г. · 21 януари 2019 г.*

## Условие

<figure className="problem-figure problem-figure--sized" style={{'--fig-w': '26.2%', '--fig-max': '168px'}}>
<img src="https://pub-43290baaaff14857b5dd59610ea438c7.r2.dev/problems/vserusiyska-2019-iii-region19t/p18-fig1.png" alt="Горизонтальное кольцо радиусом R в перспективе (эллипс), вертикальная стрелка g сверху; бусинка на ближней части кольца движется со скоростью υ0 по касательной." width="524" height="366" loading="lazy" decoding="async" />
</figure>

На тонкое проволочное кольцо радиусом $R$ свободно надета бусинка массой $m$. Кольцо неподвижно и расположено горизонтально в поле тяжести $g$. Коэффициент трения скольжения между бусинкой и кольцом равен $\mu$. В начальный момент времени бусинка движется со скоростью $\upsilon_0$.

**1)** Найдите модуль силы трения, действующей на бусинку, в начальный момент времени.

**2)** Найдите модуль полного ускорения бусинки в этот же момент.

**3)** Запишите выражение, позволяющее с погрешностью не более 2% найти путь бусинки за время, в течение которого ее скорость уменьшилась на 1%.

## Отговори

<Spoiler title="Покажи отговорите">

- **1)** $F_{\text{тр}} = \mu m\sqrt{g^2 + \left(\frac{v_0^2}{R}\right)^2}$
- **2)** $a = \sqrt{(\mu g)^2 + (1 + \mu^2)\left(\frac{v_0^2}{R}\right)^2}$
- **3)** $\Delta S = \frac{v_0^2}{\mu\sqrt{g^2 + \left(\frac{v_0^2}{R}\right)^2}}\cdot 10^{-2}$

</Spoiler>

## Решение

<Spoiler title="Покажи официалното решение">

**Возможное решение.**

1) Сила нормальной реакции опоры $\vec{N} = \vec{N}_1 + \vec{N}_2$, где $\left|\vec{N}_1\right| = mg$ – ее вертикальная составляющая, $\left|\vec{N}_2\right| = \frac{mv_0^2}{R}$ – горизонтальная составляющая в начальный момент времени. Сразу после начала движения модуль силы трения, действующей на бусинку, $F_{\text{тр}} = \mu N$, где $N = \sqrt{N_1^2 + N_2^2}$.

<figure className="problem-figure problem-figure--sized" style={{'--fig-w': '25.8%', '--fig-max': '165px'}}>
<img src="https://pub-43290baaaff14857b5dd59610ea438c7.r2.dev/problems/vserusiyska-2019-iii-region19t/p18-sol-fig1.png" alt="Кольцо (эллипс) с бусинкой: силы N1 (вверх), N2 (к центру кольца), mg (вниз), Fтр (против скорости), скорость υ0 направлена по касательной влево." width="517" height="292" loading="lazy" decoding="async" />
</figure>

Окончательно, $F_{\text{тр}} = \mu m\sqrt{g^2 + \left(\frac{v_0^2}{R}\right)^2}$.

2) Полное ускорение бусинки $\vec{a} = \vec{a}_n + \vec{a}_\tau$, где $a_n = \frac{v_0^2}{R}$ – нормальная составляющая ускорения в начальный момент времени, $a_\tau = \frac{F_{\text{тр}}}{m} = \mu\sqrt{g^2 + \left(\frac{v_0^2}{R}\right)^2}$ – тангенциальная составляющая. Сразу после начала движения модуль полного ускорения:

$a = \sqrt{a_n^2 + a_\tau^2} = \sqrt{(\mu g)^2 + (1 + \mu^2)\left(\frac{v_0^2}{R}\right)^2}$.

<figure className="problem-figure problem-figure--sized" style={{'--fig-w': '25.8%', '--fig-max': '165px'}}>
<img src="https://pub-43290baaaff14857b5dd59610ea438c7.r2.dev/problems/vserusiyska-2019-iii-region19t/p18-sol-fig2.png" alt="Кольцо (эллипс) с бусинкой: ускорения an (к центру кольца) и aτ (против скорости), скорость υ0 направлена влево." width="517" height="257" loading="lazy" decoding="async" />
</figure>

3) Необходимая точность будет обеспечена при использовании приближенных формул: $\Delta S = v_0\Delta t$; $\Delta v = a_\tau\Delta t$, где $\Delta S$ – искомый путь, $\Delta t$ – время после начала движения, за которое скорость бусинки уменьшилась на 1%.

Тогда $\Delta S = \frac{v_0\Delta v}{a_\tau} = \frac{v_0^2\cdot}{a_\tau}10^{-2} = \frac{v_0^2}{\mu\sqrt{g^2 + \left(\frac{v_0^2}{R}\right)^2}}\cdot 10^{-2}$.

**Критерии оценивания**

|  |  |  |
|---|---|---|
| 1 | Записано выражение для вертикальной составляющей силы нормальной реакции опоры $\left\vert \vec{N}_1\right\vert  = mg$ | 1 балл |
| 2 | Записано выражение для горизонтальной составляющей силы нормальной реакции опоры $\left\vert \vec{N}_2\right\vert  = \frac{mv_0^2}{R}$ | 1 балл |
| 3 | Получено выражение для силы трения $F_{\text{тр}} = \mu m\sqrt{g^2 + \left(\frac{v_0^2}{R}\right)^2}$ | 1 балл |
| 4 | Записано выражение для модуля полного ускорения $a = \sqrt{a_n^2 + a_\tau^2}$ | 1 балл |
| 5 | Записано выражение для нормальной составляющей ускорения $a_n = \frac{v_0^2}{R}$ | 1 балл |
| 6 | Получено выражение для тангенциальной составляющей ускорения $a_\tau = \mu\sqrt{g^2 + \left(\frac{v_0^2}{R}\right)^2}$ | 1 балл |
| 7 | Записаны приближенные формулы $\Delta S = v_0\Delta t$; $\Delta v = a_\tau\Delta t$ (по 1 баллу за каждую формулу) | 2 балла |
| 8 | Получен ответ в виде $\Delta S = \frac{v_0\Delta v}{a_\tau}$ | 1 балл |
| 9 | Получено конечное выражение для ответа $\Delta S = \frac{v_0^2}{\mu\sqrt{g^2 + \left(\frac{v_0^2}{R}\right)^2}}\cdot 10^{-2}$ | 1 балл |
